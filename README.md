# 无双报税自动版（wushuang-baoshui）

> 千问办公（QwenWork）Agent Skill · 浙江 · 小规模纳税人季度申报
> 作者：锤无双 ｜ 本体下载：https://chuisoft.cn/wushuang-tax.html ｜ B 站：https://space.bilibili.com/20422065

这是一个把「AI 对话」和「本地报税软件」打通的 Skill。它采用 **skill + 软件联动** 模式：配合本地单文件软件「无双报税」，你在千问办公里用自然语言对话，就能自动下载发票、自动建立账套、自动生成增值税 / 企业所得税 / 财务报表 / 财行税 / 个税五张表，并逐张产出可核对的「操作卡」，辅助你本人在电子税务局完成申报。

## 它能做什么

- **读取全自动**：CDP 登录态下载发票、拉取申报历史、读取可弥补亏损、生成财报官方导入模板、归档缴款回执。
- **写操作默认人工**：填表、提交、缴款由你在电子税务局本人完成；Skill 每张表给出「入口路径 + 要抄的确切数字 + 易踩的坑 + 校验点」的操作卡。
- **五表镜像**：增值税（小规模）/ 企业所得税 A200000 / 财务报表 / 财行税（印花税等）/ 个税扣缴端零申报。
- **多公司隔离**：每家公司独立浏览器 profile、独立端口、独立数据目录，一家做完再换下一家。

## 适用对象

当前全流程按 **浙江省电子税务局** 界面校准，面向 **小规模纳税人（按季申报）**、企业所得税查账征收的场景。申报表行次与税额口径全国统一，其他省份仅需另行校准 etax 界面路径后即可启用。

## 怎么用

1. 在千问办公里安装本 Skill（见下）。
2. 下载并打开「无双报税」本体（单文件 HTML，双击即用）。
3. 对本体说：`开始报税`，或 `下载发票` / `生成财报`。
4. 按 Skill 给出的操作卡，在电子税务局逐张核对并本人提交。

## 安装

**方式一 · 一键安装（推荐）**
在千问办公的技能页选择「本地上传」，选中本仓库的 `wushuang-baoshui.skill` 文件即可安装。

**方式二 · 手动放置**
把本目录（含 `SKILL.md`）整体复制到千问办公的技能目录：

- Windows：`%USERPROFILE%\.qwenworkcn\skills\wushuang-baoshui\`
- macOS / Linux：`~/.qwenworkcn/skills/wushuang-baoshui/`

重启或重开技能页后，技能列表出现「无双报税自动版」即安装成功。
